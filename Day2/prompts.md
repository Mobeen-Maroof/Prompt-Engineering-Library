# Day 2 – Anatomy of a Strong Prompt: The Four Levers

## Homework

### Prompt 1

#### Weak Prompt
Write an email to my professor.

#### Screenshot of Response
#### Explicit Version
Write a polite email to my professor requesting a one-week extension for my assignment.

#### Specific Version
Write a professional email (120–150 words) to my Data Science professor requesting a one-week extension due to illness. Use a respectful tone and end with a thank-you.

#### Context/Motivation Version
Write a respectful email to my Data Science professor requesting a one-week extension because I was sick and could not complete the assignment on time. The goal is to maintain professionalism and show responsibility.

### Chosen Version

Context/Motivation Version

### Reason

It clearly explains the situation, the purpose, and the desired tone, helping the AI generate a more accurate and professional email.

---

## Prompt 2

### Weak Prompt
Explain neural networks.

### Explicit Version
Explain what neural networks are.

### Specific Version
Explain neural networks to a second-year Computer Science student in about 300 words. Include how input, hidden, and output layers work, with one simple example.

### Context/Motivation Version
Explain neural networks to help me prepare for my AI exam. Focus on the core concepts, avoid unnecessary mathematics, and include one real-world application.

### Chosen Version

Context/Motivation Version

### Reason

It tells the AI why the explanation is needed, so the answer becomes more focused and useful for exam preparation.

---

## Prompt 3

### Weak Prompt
Fix my resume.

### Explicit Version
Improve my resume.

### Specific Version
Improve my resume for an entry-level Machine Learning internship. Correct grammar, improve formatting, and highlight technical skills, projects, and education while keeping it to one page.

### Context/Motivation Version
Improve my resume so I can apply for Machine Learning internships. Make it ATS-friendly, professional, and emphasize AI, Python, and Data Science projects.

### Chosen Version

Context/Motivation Version

### Reason

It specifies the purpose of the resume and the target job, allowing the AI to make better improvements.

---

## Prompt 4

### Weak Prompt
Give me some project ideas.

### Explicit Version
Give me five AI project ideas.

### Specific Version
Suggest five intermediate-level Machine Learning projects using Python. Include the dataset, algorithms, difficulty level, and expected learning outcomes in a table.

### Context/Motivation Version
Suggest five Machine Learning projects that I can build for my GitHub portfolio to strengthen my resume for internship applications. Include real-world problems and recommended datasets.

### Chosen Version

Context/Motivation Version

### Reason

It explains how the projects will be used, resulting in more practical and portfolio-worthy suggestions.

---

## Prompt 5

### Weak Prompt
Review this code.

### Explicit Version
Review the following Python code and identify any issues.

### Specific Version
Review this Python code for readability, performance, coding style, and possible bugs. Suggest improvements and explain each recommendation with examples.

### Context/Motivation Version
Review this Python code as if you were conducting a professional code review for a junior developer. Focus on maintainability, performance, and best practices because the code will be submitted as part of an academic project.

### Chosen Version

Context/Motivation Version

### Reason

It defines the reviewer’s perspective and the purpose of the review, resulting in more detailed and useful feedback.

---

## Conclusion

Day 2 taught me that a strong prompt is created by combining four important elements:

- Be explicit about what you want.
- Be specific with details and constraints.
- Provide context or motivation.
- Clearly describe the desired output.

Using these techniques makes AI responses more accurate, relevant, and easier to use without requiring significant editing.
