[Document 1 - Artificial Intelligence]

Artificial Intelligence (AI) is a field of computer science focused on creating systems that can perform tasks that normally require human-like intelligence. These tasks can include reasoning, learning, problem solving, language understanding, and decision making.


[Document 2 - Machine Learning]

Machine Learning (ML) is a subset of Artificial Intelligence. Machine learning systems learn patterns from data and use those patterns to make predictions or decisions. Common approaches include supervised learning, unsupervised learning, and reinforcement learning.


[Document 3 - Deep Learning]

Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers. Deep learning models can learn complex patterns from large datasets and are widely used in computer vision, natural language processing, and speech-related applications.


[Document 4 - Retrieval-Augmented Generation]

Retrieval-Augmented Generation (RAG) combines information retrieval with language generation. A RAG system first retrieves relevant information and then provides that information to a language model so the model can generate an answer using the retrieved context.


[Document 5 - Large Language Models]

Large Language Models (LLMs) are machine learning models trained on large amounts of text. They can perform tasks such as text generation, summarization, question answering, classification, and reasoning.


[Document 6 - Prompt Engineering]

Prompt Engineering is the practice of designing and refining instructions given to a language model. Clear instructions, examples, constraints, and output formats can help guide model behavior.


[Document 7 - Tool Calling]

Tool calling allows an AI model to request the execution of an external function or tool. The model can decide when a tool is useful, provide the required arguments, and use the tool result when generating its response.


[Document 8 - Structured Output]

Structured output means returning information in a predefined format such as JSON. Structured outputs make it easier for software applications to validate and process model responses.


[Document 9 - Prompt Injection]

Prompt injection is an attack in which untrusted input attempts to manipulate an AI system into ignoring its original instructions or performing unintended actions. Retrieved documents and external content should therefore be treated as untrusted data.


[Document 10 - AI Security]

AI applications can use security measures such as input validation, output validation, least-privilege tools, safe parsers, and clear trust boundaries. These measures can reduce the risk of unintended behavior.
